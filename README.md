# Chad's World Tour

An interactive comic lab for AP Human Geography Topic 3.1 (Introduction to Culture). The class acts as cultural consultants and guides Chad, a clueless business traveler, through four stops: Shanghai, Tokyo, Bangkok, and Toledo.

## Publish with GitHub Pages

1. Create a new public repository on GitHub (for example, `chads-world-tour`).
2. Upload everything in this folder to the repository, keeping the `img` folder as it is. `index.html` must sit at the top level.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, then click **Save**.
5. Wait a minute or two. Your link will be `https://YOUR-USERNAME.github.io/chads-world-tour/`.

## Running it in class

- Use the tabs at the top to jump between stops. Choices are permanent, and the Trust Meter drops with each mistake.
- Keyboard: 1, 2, 3 pick an answer. Enter or the right arrow moves on.
- The **Comic pages** button lets you swap in a new page image. Swapped pages are saved only in that browser.
